## Important: inquiry form
The form uses `mailto:` to open the visitor's email application with a prefilled message. The visitor must press Send; it does not submit to a backend. For reliable direct submissions, connect a hosted form service or backend later.

## Publish on GitHub Pages
1. Create a new **public** GitHub repository (for example `vexo-digital`).
2. Upload `index.html` to the repository root and commit.
3. In Settings > Pages, select Deploy from a branch, `main`, `/ (root)`, then Save.
4. Wait for the Pages deployment to finish.
